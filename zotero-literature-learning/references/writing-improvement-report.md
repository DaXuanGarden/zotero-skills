# Writing improvement report

The main user-facing artifact is `writing_improvement_report.md`. Supporting ledgers are appendices; users should not need to inspect every file to understand the recommendations.

## Report sections

```markdown
# Writing Improvement Report

## 1. Writing Contract
## 2. Reading Basis
## 3. Peer Argument Patterns
## 4. Transfer Decisions
## 5. Manuscript Writing Diagnosis
## 6. Revision Cards
## 7. Transferable Writing Principles
## 8. Author Checks
## 9. Unresolved Questions
## 10. Handoff
```

## Revision card table

```markdown
| Revision | Location | Reader problem | Writing action | Before/after | Peer pattern | Transfer scope | Claim delta | Priority | Author check |
|---|---|---|---|---|---|---|---|---|---|
```

Every recommendation must explain the reasoning gain. “More native” or “more like the target journal” is not sufficient evidence for a revision.
